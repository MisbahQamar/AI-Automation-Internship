Task Description
Build an automation that connects Google Forms, Google Sheets, and Gmail.
Workflow
Google Forms → Google Sheets → Gmail.
Test Input & Output
A sample course-registration response was submitted/tested. The response was successfully detected, sent to Google Sheets, and a Gmail message was successfully sent.
Important Configuration
Google Forms: New Form Response
Google Sheets: Create Spreadsheet Row
Gmail: Send Email
Dynamic fields such as Name, Email, Course, and Batch were mapped from the form response.
How It Works
When a user submits the Google Form, the response is captured by Zapier. The information is added to Google Sheets and a confirmation email is sent through Gmail.
